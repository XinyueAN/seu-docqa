# 课程要求映射与验收清单

本文把课程项目要求映射到代码入口和可见验收动作。实际验收前应按“运行准备”完成依赖安装、配置模型并使用自有文档验证；本仓库没有随项目分发用户的私有资料或 API 密钥。

| 要求方向 | 对应实现 | 验收动作 | 当前边界 |
|---|---|---|---|
| PDF、Word、PPT 转结构化 Markdown | `docqa/doc2md/parser.py`；上传任务接口 | 上传含标题、正文、表格、图片的样例，查看文档详情预览 | PDF 保留物理页码；DOCX 页码近似；PPT 按幻灯片编号 |
| 文本、表格、图片抽取与图文关联 | `docqa/web/app.py` 上传流程；图片归档接口 | 检查正文、图片页码及 Markdown 图片章节 | 复杂版式与跨页表格需人工核对 |
| OCR / 视觉理解 | 上传选项、`docqa/service/llm.py` `describe_image` | 上传扫描页或图表并主动选择 DeepSeek 图片理解 | 需网络和模型支持；关闭时不发送图片；无本地 OCR |
| 本地文档库与切片 | `docqa/docbase/store.py` SQLite；Markdown 和图片文件保存在 `data/` | 上传文档后检查文档数量、知识片段与详情 | 本地优先，不代表所有临时请求都完全离线 |
| 混合检索与重排 | `docqa/docbase/retriever.py` BM25、TF-IDF、RRF；可选向量与 Cross-Encoder | 在检索实验室查看各召回通道和融合排序 | BGE 模型需安装额外依赖及权重；默认关闭 |
| Agent 按约定回答并提供来源 | 根目录 `AGENTS.md`、`docqa/agent/answer.py`、`/api/chat` | 提问后核对 `[S#]` 与来源卡片的文档、页码、摘录 | Agent 通过多子查询扩展证据并一次生成回答；非通用工具调用型 Agent |
| 可追溯图文来源 | 引用卡片包含文档名、页码、摘录及相关图片预览 | 从答案引用跳转到来源卡片 | 来源定位精度取决于解析质量 |
| 增量目录监控 | `docqa/service/watcher.py` 与 `/api/watcher` | 将新文件复制至 `data/watch/`，观察状态与文档列表 | 删除源文件不自动删除知识库记录；监控导入不调用云视觉 |
| 解析进度与交互界面 | `/api/jobs`、中文单页工作台 | 上传多份文档查看处理阶段；查看设置、预览与分类 | 任务状态保存在进程内，重启后任务状态过期 |
| 检索评估 | `docqa/service/evaluation.py` 与评估面板 | 用当前文档名添加标注样例，运行 Recall@K、Hit Rate、MRR | 数据集保存在本地 `data/evaluation.json`；结果依赖语料和配置 |

## 建议验收顺序

1. 配置本地模型密钥，启动服务；确认密钥仅显示“已配置”，不出现在前端或日志中。
2. 上传一份含多页正文的 PDF、一份含表格/图片的 DOCX 或 PPTX，并记录解析片段数量。
3. 查看正文预览及图片页码；需要验证图像问答时，再明确勾选云端视觉分析。
4. 使用可在文档中核验的问题提问，检查回答中的引用、页码与摘录。
5. 在检索实验室记录 BM25、TF-IDF、语义通道（启用时）、RRF 与重排结果。
6. 以真实文档文件名标注一组问题，运行评估并将语料规模、Top-K、启用模型与指标一起写入报告。
7. 将演示环境、限制和失败案例如实写入报告，不把单一小样本的分数描述为普遍性能。
